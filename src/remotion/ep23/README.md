# 第 23 期（含水量：8.5% 是上限）交付说明

Neon（Gemini）出初版，hark-ahren 审核并收尾（2026-11-24）。

## 全片通用（每拍都生效）

- **线条抖动**：刻度尺、文件、毛笔线每 3 帧换一组 1–2px 偏移（`kit/hand.ts` 的 boil 系列）。boil 按真实帧计，不跟一拍二走，抖动节奏均匀。文字和茶饼本体不抖。
- **一拍二**：每拍 `draw()` 里 `frame = onTwos(rawF)`，主体动作按偶数帧走；镜头（`beatCamera(rawF)`）、粒子、光斑仍逐帧。
- **微呼吸**：`renderLayers` 给主体层整体加 `idleBreathe`（缩放 ≤ 0.8%、上下 ≤ 2px），片尾 0.5 秒静止时也保留。
- **镜头**：每拍 `cameraAt` 整拍慢推约 1.00→1.045，焦点跟口播移到当前主角；纸纹 0.35、光斑 0.55、主体 1、碎叶 1.35 分层视差。
- **画面字最小 54px**：`kit/draw-kit.ts` 的 `MIN_TEXT_PX`，包装、印章里的字用 `fixed: true` 跳过。

## 镜头衔接

没有做跨拍衔接：HTML 节拍之间隔着马老师的真人口播镜头，前后两拍不会直接相接，硬对齐位置意义不大。`kit/hand.ts` 里的 `ANCHORS` 保留，以后连续两拍直接相接时可用。

## 新增 / 改动的 kit 函数

- `kit/hand.ts`：`boilStep / boilOffset / boilPolyline / drawBoilBrushStroke / traceBoilLine / traceBoilRect`（线条抖动），`setRawFrame / rawFrame`，`onTwos`，`idleBreathe`，`anticipateMove`，`followThrough`，`ANCHORS`
- `kit/vo.ts`：`VO.charFrames(phrase, displayLen?, nth?)`——关键词逐字开口帧
- `kit/draw-kit.ts`：`drawBeatText`（逐字落下、重音 1.15–1.25 倍）、`beatWord`（按口播词组调用 drawBeatText 并补淡墨底）、`MIN_TEXT_PX`
- `kit/objects.ts`：`drawMoistureScale`（全片水分刻度尺）、`drawMiyunCakeWithDamp`（蜜韵受潮发暗、潮斑）
