# 新建一期（定制动画）

面板、目录、导出管线都是固定的。**每一期只需要写这一期的动画本身**，不用改 `catalog.ts`、`clip-data.ts` 或任何面板代码——
`src/remotion/epNN/<节拍>/index.ts` 一保存，面板「定制期」里就自动出现。

## 四步

1. **建节拍文件夹**（每个节拍一次）

   ```bash
   npm run new:clip -- 20 B1 开门大字 --episode-title "茶叶怎么醒"
   npm run new:clip -- 20 B2 三个误区
   npm run new:clip -- 20 B4-1 避光密封 --seconds 5
   ```

   生成 `src/remotion/ep20/b1/` 等文件夹（`data.ts` / `Comp.tsx` / `draw.ts` / `index.ts`），第一次还会生成
   `src/remotion/ep20/episode.ts`（本期标题）。打开面板 → 期下拉框「定制期」→ 第 20 期，马上能预览。

   可选：`--from-template <模板id>` 把一个模板复制进文件夹当起手代码（如 `hook-stamp`、`duel`、`rule-cards`），
   之后它就是这个节拍私有的代码，随便改；`--slug 名字` 自定义文件夹名；`--note "…"` 面板里的一行说明。

2. **写动画**（这一步才是每期真正要做的事）
   - `data.ts`：默认文案、时间点（`framesOf(秒)`）、音效 `sfxHits`。
   - `Comp.tsx`：预览用的 Remotion 组件。文案用 `useCustomText("key", 默认值)` 读，纸色用 `usePaperColors()`，字号用 `useFontSizeScale()`。
   - `draw.ts`：导出用的逐帧画布（1080×1920）。和 `Comp.tsx` 读同一份 `data.ts`，保证预览 = 导出。
   - 可复用的工具：`@/remotion/shared/appear`（弹簧入场）、`breath`（呼吸）、`paper`、`draw-paper`、`theme`、`sfx`。

3. **填 `index.ts`**：`defineClip({...})` 里写面板要的东西
   - `fields`：右侧可改的文案（`key` 与 Comp/draw 里读的一致，`type: "stamp"` 是印章字）
   - `markers`：时间轴上的关键帧标记
   - `exportName` / `note` / `title`：导出文件名与列表显示
   - 排序默认按编号自然排序（B1 < B2 < B4-1 < B10），需要时加 `order`

4. **预览、改字、导出**：在面板里检查每个节拍，改文案，单个或「批量导出本期」。

## 小贴士

- 删除一个节拍 = 删掉它的文件夹；面板会自动把它从定制期里拿掉。
- 片段 id 规则 `ep<期>-<编号小写>`（如 `ep20-b4-1`），不要和已有的重复（脚本会检查）。
- 面板里对定制期的修改（文案、顺序、导出名）存在本机浏览器；动画本身永远以代码为准。
- 模板（`src/templates/`）仍然可用：「新建一期 → 从模板起步」或 `--from-template`，但不是主路径。
