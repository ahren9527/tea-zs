# 小正（代码角色）

小正是固定资产，各期共用，**不要在 epNN 里自己重画小正**。代码在 `src/remotion/shared/characters/`，视角、姿势和表情一览见 `docs/img/小正-一览.png`。形象依据：`attachments/角色设定卡.png`、`attachments/小正-三视图.png`、`attachments/小正-表情表.png`。

## 调用

```ts
import { drawXiaozheng, xiaozhengIdle } from "@/remotion/shared/characters";

// 原点 = 两脚中间的地面点；第二个参数是头顶到脚底的像素高
ctx.save();
ctx.translate(760, 1500);
drawXiaozheng(ctx, 620, {
  ...xiaozhengIdle(frame),        // 自动眨眼 + 呼吸（按帧号，确定性）
  pose: "stand",
  poseTo: "holdCup",
  poseMix: easeOutCubic(progress(frame, 30, 48)), // 0→1 从站立过渡到捧杯
  expr: "smile",
});
ctx.restore();
```

## 参数（全部是数，可逐帧插值）

| 参数 | 说明 |
|---|---|
| `view` | 视角：`front` 正面（默认，全部姿势）、`side` 侧面朝画面右（`flip` 朝左）、`back` 背面。侧面 / 背面只有站和走 |
| `walk` | 侧面走路相位，每 +1 走一整步，如 `frame / 26`；不传就是站着。走路时整体平移由你自己做 |
| `pose` / `poseTo` / `poseMix` | 姿势与过渡：`stand` 站立、`holdCup` 双手捧杯、`touchHead` 摸摸光头、`straighten` 扶正茶杯（低头、手在低处）、`wave` 打招呼。`poseMix` 0 = pose，1 = poseTo。茶杯跟手走，两手靠拢时淡入 |
| `expr` | 表情：`smile` 微笑、`calm` 平静、`happy` 开心、`sip` 品茶闭眼、`curious` 好奇、`think` 思考、`surprised` 小惊讶、`shy` 不好意思、`sleepy` 半睁眼、`awkward` 为难（侧面只支持其中一部分） |
| `blink` | 0..1 眨眼（通常用 `xiaozhengIdle` 给的值） |
| `breath` | 0..1 呼吸相位 |
| `tilt` | 歪头，弧度，±0.06–0.12 比较自然 |
| `look` | 眼珠方向 `{x, y}`，-1..1 |
| `rub` | 摸头 / 挥手的来回，配合 `touchHead` 或 `wave`，让它随时间增长（如 `frame / 20`） |
| `flip` | 左右镜像 |
| `tea` | 杯里有没有茶，默认 true |
| `lineScale` | 线条粗细倍数，小人（高度 < 300px）用 1.3 左右 |

## 规矩

- 一屏一个焦点：小正出场时，大字少、物件少；字出现时按老规矩「字左物右」，小正让到右边。
- 主体避开视频号右侧 120px、底部 300px（x ≤ 950、y ≤ 1560）：原点 y 不要超过 1560。
- 小正不张嘴说话（口播是马老师的），`happy` 只用于笑一下。不说教、不卖弄、不神化功效。
- 产品仍从 `shared/products` 取；小正捧的是他自己的小白瓷杯。
- 需要新视角、新表情或新姿势时，先跟宋元提，统一加进 shared，不在某一期里临时画。
