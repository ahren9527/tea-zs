# 动效库 `src/remotion/shared/fx/`

目标：让节拍像「镜头拍出来的」，不是 PPT。所有动效都是 **帧号 → 数值 的纯函数**（不用 `Math.random()`、不累积状态），
所以 `draw.ts`（导出）和 `Comp.tsx`（预览）算出来的一模一样。

- `import { … } from "@/remotion/shared/fx"` —— 纯函数 + canvas 绘制（draw.ts 用，不带 React）
- `import { … } from "@/remotion/shared/fx/react"` —— React 包装（Comp.tsx 用）

| 模块 | 内容 |
| --- | --- |
| `camera` | `cameraAt(frame, length, {from,to,drift,focus,focusBlur})` 整拍推近 1.00→1.06 + 低频漂移 + 焦点移动；`withLayer(ctx, cam, depth, fn)` 按层深度视差（0=钉屏，1=主体，>1=前景）；`layerCss` / `<CameraLayer>`；`layerBlur` 背景虚焦；`cameraKick` 落地小震 |
| `springs` | `heavyLand`（茶饼/印章：加速落下、压扁、回弹）、`lightFloat`（叶/香：慢浮轻荡）、`sealPress`（提起预备 → 砸下 → 印泥洇开）、`springValue` 通用阻尼弹簧 |
| `texture` | `drawRicePaper`（纸色+纤维+帘纹，缓存）、`drawGrain`（逐帧不同的确定性颗粒）、`drawVignette`、`drawWindowLight`（左上暖窗光 + 斜光带，和 AI 场景的窗光一致） |
| `ink` | `inkBloomShapes` / `drawInkReveal`：水墨晕染显现（几团毛边墨晕长大 + 淡墨洗 + 湿边）；React `<InkReveal>` 用同一组多边形做 SVG mask |
| `stroke` | `drawBrushStroke` / `brushOutline`：毛笔笔触沿路径生长（起笔重、收笔尖、可飞白）；`partialPolyline` 按弧长截取；`jaggedPath` 裂纹；React `<GrowStroke>` |
| `seal` | `drawSeal`：崩边白文方印，斑驳印泥、略带旋转，配合 `sealPress`；`<SealStamp>` |
| `motion` | `breathe`、`lightSpots`/`drawLightSpots`（窗光浮尘）、`steamWisps`/`drawSteam`（水汽）、`leafParticles`/`drawLeafParticles`（碎叶）、`traceLeaf` |
| `palette` | `fxPalette(theme)`：小正配色（暖米白 #F3EADB · 燕麦米 #E3CFB4 · 茶褐 #7A4E33 · 竹青绿 #6B7A4F · 朱砂红 #B5332A）与面板纸色主题调和；`rgba` / `mixHex` |
| `math` | 缓动（全部非线性）、`window01`、确定性随机 `hash01` / `rng`、噪声 `noise1` / `noise2` |
| `surface` | 离屏画布工厂（浏览器自动；Node 渲染脚本注入 @napi-rs/canvas） |

## 推荐写法（参考 `src/remotion/ep20/b4/`）

`draw.ts` 用 canvas 画完整一帧，`Comp.tsx` 只写：

```tsx
<FxCanvas draw={(ctx, frame) => draw(ctx, (frame / FPS) * 1000, params)} fontsReady={ensureFonts(text)} />
```

预览 = 导出，不需要两边各写一遍。每帧的层次：宣纸（depth 0.35）→ 浮尘 → 主体（depth 1）→ 前景碎叶（1.35）→ 文字带（0.12）→ 窗光 / 暗角 / 颗粒。

## 规矩

- 不用投影卡片、圆角色块、通用图标、线性缓动。用「物」讲事，字少（同屏 ≤ 12 字），大小对比。
- 底部 300px 留给字幕。
- 时间点从口播推（见 ep20/b4/data.ts 的 `voAt("词")`），改语速只改一个常数。

## 在 Node 里看帧

```bash
# 依赖装在仓库外任意目录：npm i @napi-rs/canvas esbuild；字体放一个目录（文件名含 wenkai / serif）
RENDER_DEPS=/path/to/deps RENDER_FONTS=/path/to/fonts \
  node scripts/render-frames.mjs src/remotion/ep20/b4/draw.ts 2 9.4 13.9 17.9 --out screenshots/ep20-b4
```
