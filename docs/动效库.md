# 动效库 `src/remotion/shared/fx/`

目标：让节拍像「镜头拍出来的」，不是 PPT。所有动效都是 **帧号 → 数值 的纯函数**（不用 `Math.random()`、不累积状态），
所以 `draw.ts`（导出）和 `Comp.tsx`（预览）算出来的一模一样。

- `import { … } from "@/remotion/shared/fx"` —— 纯函数 + canvas 绘制（draw.ts 用，不带 React）
- `import { … } from "@/remotion/shared/fx/react"` —— React 包装（Comp.tsx 用）

| 模块      | 内容                                                                                                                                                                                                                                                     |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `camera`  | `cameraAt(frame, length, {from,to,drift,focus,focusBlur})` 整拍推近 1.00→1.06 + 低频漂移 + 焦点移动；`withLayer(ctx, cam, depth, fn)` 按层深度视差（0=钉屏，1=主体，>1=前景）；`layerCss` / `<CameraLayer>`；`layerBlur` 背景虚焦；`cameraKick` 落地小震 |
| `springs` | `heavyLand`（茶饼/印章：加速落下、压扁、回弹）、`lightFloat`（叶/香：慢浮轻荡）、`sealPress`（提起预备 → 砸下 → 印泥洇开）、`springValue` 通用阻尼弹簧                                                                                                   |
| `texture` | `drawRicePaper`（纸色+纤维+帘纹，缓存）、`drawGrain`（逐帧不同的确定性颗粒）、`drawVignette`、`drawWindowLight`（左上暖窗光 + 斜光带，和 AI 场景的窗光一致）                                                                                             |

| `stroke`  | `drawBrushStroke` / `brushOutline`：毛笔笔触沿路径生长（起笔重、收笔尖、可飞白）；`partialPolyline` 按弧长截取；`jaggedPath` 裂纹；React `<GrowStroke>`                                                                                                  |

## 推荐写法（参考 `src/remotion/ep20/b2/`，本期共用件在 `src/remotion/ep20/kit/`）

`draw.ts` 用 canvas 画完整一帧，`Comp.tsx` 只写：

```tsx
<FxCanvas
  draw={(ctx, frame) => draw(ctx, (frame / FPS) * 1000, params)}
  fontsReady={ensureFonts(text)}
/>
```

预览 = 导出，不需要两边各写一遍。每帧的层次：宣纸（depth 0.35）→ 浮尘 → 主体（depth 1）→ 前景碎叶（1.35）→ 文字带（0.12）→ 窗光 / 暗角 / 颗粒。

## 规矩

- 不用投影卡片、圆角色块、通用图标、线性缓动。用「物」讲事，字少（同屏 ≤ 12 字），大小对比。
- 底部 300px 留给字幕。
- 时间点从口播推（见 ep20/b2/data.ts 的 `voAt("词")`，由 `kit/draw-kit.ts` 的 `makeVoAt(口播, 字每秒, 起点秒)` 生成），改语速 / 配音偏移只改 `CHARS_PER_SEC` / `VO_START_SEC`。

## 在 Node 里看帧

```bash
# 依赖装在仓库外任意目录：npm i @napi-rs/canvas esbuild；字体放一个目录（文件名含 wenkai / serif）
```

## 音效 `src/remotion/shared/sfx-lib.ts`

风格：**高级、克制、少而准**。音效是「物」的声音，不是 UI 提示音；观众应该"感觉到"而不是"听到"。

### 声音清单（`public/tea/sfx/`，来源与 CC0 许可证见 `public/tea/sfx/LICENSES.md`）

| `foley()` 名   | 文件                             | 用在什么时候                            |
| -------------- | -------------------------------- | --------------------------------------- |
| `cakeThud`     | cake-thud / cake-thud-2          | 茶饼落到木桌（闷、沉、软）              |
| `paperRustle`  | paper-rustle / paper-rustle-2    | 棉纸翻动、揭开一角（短）                |
| `paperTear`    | paper-tear                       | 棉纸撕开（短）                          |
| `foilCrinkle`  | foil-crinkle / foil-crinkle-2    | 铝箔袋揉动                              |
| `foilSeal`     | foil-seal                        | 自封袋 / 铝箔袋压封口                   |
| `needlePierce` | needle-pierce / needle-pierce-2  | 茶针扎进紧压的饼                        |
| `needleScrape` | needle-scrape                    | 茶针沿饼面撬、刮                        |
| `cakeCrack`    | cake-crack / cake-crack-2        | 饼块撬开、掰裂                          |
| `leafScatter`  | leaf-scatter                     | 碎叶散落（跟在 cakeCrack 后，音量 0.5） |
| `jarLid`       | jar-lid / jar-lid-2              | 陶 / 紫砂罐盖合上                       |
| `sealWood`     | seal-wood                        | 木印章压下                              |
| `clothUnroll`  | cloth-unroll                     | 布展开                                  |
| `scrollUnroll` | scroll-unroll                    | 卷轴展开                                |
| `paperweight`  | paperweight                      | 镇纸压到木面                            |
| `whoosh`       | whoosh-soft / whoosh-soft-2      | 镜头大幅运动（极轻，尽量不用）          |
| `brandHit()`   | zheng-pluck（默认）/ bowl-strike | **只给**口诀落印、金句                  |
| `roomBed()`    | room-tone（20 s 无缝循环）       | 整拍底噪：极淡的室内空气 + 远风         |

一物一声：同一个物件整期只用它那一组录音；有变体时 `foley()` 按帧号确定性挑一个，避免机关枪式重复。

### 响度（已统一处理，写 beat 时不用再调 EQ）

- 物件音效：48 kHz / 16-bit 单声道，高通 80 Hz，1–4 kHz 下挖 3.5 dB（让位人声），峰值 ≤ -12 dBFS、短时响度 ≤ -30 LUFS。
- 品牌声：峰值 -12 dBFS，带自然余韵（3–4 s）。
- 底噪：-40 LUFS，等功率交叉做的无缝循环。
- 总线 `SFX_MASTER = 0.8`（所有音效都乘它，包括旧片段）。`foley()` 默认 volume 1 → 混音后峰值约 -14 dBFS；`brandHit()` 默认 0.7；`roomBed()` 自动抵消总线，混音后仍是 -40 LUFS。
- 重建 / 加新声音：改 `scripts/sfx/build-foley.py` 里的表，`python3 scripts/sfx/build-foley.py`（需要 ffmpeg + numpy），并在 LICENSES.md 记来源。

### 写法（beat 的 `data.ts`）

```ts
import { brandHit, foley, roomBed } from "@/remotion/shared/sfx-lib";

export function sfxHits(_staggerFrames: number) {
  return [
    foley("paperRustle", voAt("揭开")),
    foley("cakeThud", HITS[0]), // 默认 volume 1、vary 0.03（±3% 音高 / 音量，确定性）
    foley("needlePierce", HITS[1], { volume: 0.85 }),
    foley("cakeCrack", HITS[2]),
    foley("leafScatter", HITS[2] + 4, { volume: 0.5 }),
    brandHit(SEAL_AT), // 口诀落印；{ kind: "bowl" } 换成钵声
    roomBed(), // 可选：整拍底噪（或者在 index.ts 里写 ambience: true，二选一）
  ];
}
```

- `SfxHit` 字段：`src`、`at`（帧）、`volume`、`vary`（数字或 `{ pitch, volume }`，按 src+at 确定性浮动）、`rate`、`loop`、`fadeIn` / `fadeOut`（帧）、`until`（帧）。旧写法 `{ src, at, volume }` 完全兼容。
- 底噪也可以在 `index.ts` 里开：`defineClip({ …, ambience: true })` 或 `ambience: { volume: 1, fadeIn: 30 }`。预览和导出都会自动加，**不要**再在 sfxHits 里写 `roomBed()`。
- 预览（`SfxTrack`）与导出（`src/lib/sfx-mix.ts`）用同一个 `resolveHit()`，音量 / 随机 / 包络一致。注意：预览里浏览器变速会保持音高，只有导出会真正变调（±3% 听不出差别）。

### 混音规矩

1. **少而准**：只给主动作配音（落、撕、扎、裂、封、盖、印）。文字出现、箭头、标注不配音。
2. **≤ 1 下 / 0.5 秒**（≈ 15 帧）。两个动作挨着时只留重的那下；碎叶这种附属声跟在主声后 3–6 帧、音量减半。
3. **品牌声只给口诀落印 / 金句**，一拍最多一次，一期最多两三次。
4. **底噪永远很低**（-40 LUFS）。只有整拍是安静"物"的镜头时才开；有大量动作的拍可以不开。
5. 音效打在动作的**接触帧**（落地、刺入、合盖那一帧），不要提前；口播重音和音效撞在同一帧时，音效让 2–3 帧。
6. whoosh 尽量不用；用了就 volume ≤ 0.5，且只给真正的大镜头运动。

### 导出（面板「导出当前分镜」/ 批量导出都有）

- **音效：合成进视频**（默认）：和以前一样，MP4 里带 AAC 音效轨。
- **音效：分轨：无音效视频 + WAV**：先下载 `…_音效.wav`（48 kHz / 16-bit 立体声），再下载 `…_无音效.mp4`（或 .webm）。WAV 长度严格 = 片段帧数 ÷ 29.97 秒（采样数 = round(帧数 / 29.97 × 48000)），剪映里两条轨首帧对齐即可，方便单独压低 / 换掉音效。
- 静态站（`npm run build:static`）同样可用：混音全在浏览器 OfflineAudioContext 里做，不依赖服务器。
- 冒烟测试：`node scripts/sfx-export-smoke.mjs <站点URL> <输出目录>`（Playwright；`MIX_DEV=1` 时在 vite dev 里直接混一段新音效库样例）。
